## 支付宝在 Evoxt 上具体怎么付

流程比其他海外商家短，因为 Evoxt 的后台本身有中文界面。

1. 用邮箱注册账号，设密码，验证邮件。
2. 进后台，选 Deploy → Cloud Virtual Machines。
3. 先选机房节点，再选套餐配置，然后选操作系统镜像。
4. 结账页选支付宝，跳转扫码，手机确认付款。
5. 付款到账后系统自动部署，约 2.5 分钟收到含 IP 与登录信息的邮件。

整个过程不需要填信用卡号。同一结账页也提供微信、PayPal、信用卡和加密货币，哪个通道顺手用哪个。

两个容易忽略的点。付款成功不等于立刻能登录，要等自动部署跑完那两三分钟；装 Windows 的话，系统镜像选项只有在 2GB 内存及以上的套餐才会出现，512MB 和 1GB 档只能装 Linux。

支付宝解决的是付款环节，跟机器跑得快不快、国内访问延迟高不高没有关系。这两件事分开判断。

## 哪一档开始才有意义

按用途倒推比按价格排序有用。

**512MB 档（$2.99）**：跑监控脚本、定时任务、做 SSH 跳板、学 Linux 命令。装个宝塔面板内存就见底了，建站不合适，也装不了 Windows。适合先花三美元验证一下这台机器到你这儿的网络状况。

**1GB 档（$4.99）**：单一轻量站点、小型反代、个人用的代理服务。比 512MB 档多一倍内存和硬盘，价格多 $2，但流量还是 500GB，装 Windows 依然不够。

**2GB 档（$5.99）**：分界线在这一档。能装 Windows，能同时跑 Docker、数据库和 Web 服务，能装面板不卡。第一次买 Evoxt 又不知道自己需要多少内存的，从这档起不容易返工。

**2 核 2GB 档（$6.95）**：这一档值得单独说。它比 2GB 档只贵 **$0.96**，换来多一个 CPU 核心和翻倍到 2TB 的月流量。同样是 2GB 内存，多花不到一美元，并发请求处理能力和流量余量都上一个台阶。如果不是预算卡到分，$6.95 这档的性价比实际高于 $5.99 那档，很多套餐对比表会漏掉这个差价。

**2 核 4GB 档（$11.99）**：多站点、稍重的应用、Windows 上加面板和数据库同时跑。到这一档，瓶颈通常已经不在 CPU 而在你的带宽和访客量。

## 哪些人不必考虑 Evoxt

**要 CN2 GIA 级别回国线路的。** Evoxt 不是这条路线上的产品，第三方价格站点也明确把它列在"不适合 CN2 GIA 高端用户"这一类。香港、日本、韩国机房对亚太延迟友好，但别拿它跟专做 GIA 优化的商家比回国质量。真需要那类线路，预算要按另一个量级准备。

**跑高带宽生产负载的。** 每档的带宽上限公开页面没有逐项写明，优化线路还会砍流量。拿它做视频分发、大文件下载站，容易在流量上卡住。

**必须中文工单沟通的。** 后台界面能切中文，但客服是否中文值守，现有资料没有说明。如果你的业务要求出问题能中文对话解决，下单前先发一封工单试试响应。

**只用几天的临时需求。** 最低档月付 $2.99，已经是很低的试错成本，没必要为了省一点去年付，反而把自己锁在长周期里。

1. **续费价**。首单价和续费价是否一致，结算页会写清楚，长周期套餐尤其要看清第二期开始收多少。
